# Strategy

This section is the authoritative strategy framework for the Mile High Dreamin Salesforce implementation.

## Reading order

1. [Org strategy](01-org-strategy.md) — scope, architecture, data model, outcomes, revenue, and governance.
2. [Implementation plan](02-implementation-plan.md) — delivery phases, backlog, nine core automation outcomes, reports, and user outcomes.
3. [Admin runbook](03-admin-runbook.md) — executable configuration, administration, testing, privacy, deployment, and operating procedures.
4. [Risk register](04-risk-register.md) — blank framework populated by each implementation executor.
5. [Decision register](05-decision-register.md) — authoritative approved decisions and supersession history.

Related discovery artifacts: [Hybrid execution framework](../02-discovery/04-execution-framework/README.md) · [Prebuild gates](../02-discovery/05-prebuild-gates.md).

## Authority

- Approved decisions control when another document is ambiguous.
- The org strategy controls scope and architecture.
- The implementation plan controls delivery outcomes and sequence.
- The admin runbook controls execution and operations.
- Prebuild Status, Evidence / Decision, and Owner fields remain blank until an executor applies the framework.
- The implementation section is an executor landing page; it does not claim that org-specific metadata has been built.
