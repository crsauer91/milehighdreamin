# Strategy

This section is the authoritative, frozen strategy framework for the Mile High Dreamin Salesforce implementation.

## Reading Order

1. [Org strategy](01-org-strategy.md) — scope, architecture, data model, outcomes, revenue, and governance.
2. [Implementation plan](02-implementation-plan.md) — delivery phases, backlog, automation, reports, and user outcomes.
3. [Admin runbook](03-admin-runbook-mile-high-dreamin-admin-playbook.md) — executable configuration, administration, testing, privacy, deployment, and operating procedures.
4. [Risk register](04-risk-register.md) — blank framework populated by each implementation executor.
5. [Decision register](05-decision-register.md) — authoritative approved decisions and future supersession history.

## Authority

- Approved decisions in the decision register control when another document is ambiguous.
- The org strategy controls scope and architecture.
- The admin runbook controls execution and operations.
- Prebuild Status, Evidence / Decision, and Owner fields remain blank until an executor applies this framework.
- Downstream implementation artifacts may remain incomplete without reopening the frozen strategy.
