# Implementation

This section is the executor landing page for applying the Mile High Dreamin framework to a Salesforce org.

No deployable Salesforce metadata, credentials, client data, completed gate evidence, or placeholder automation files are stored in this reusable repository.

## Start here

1. Confirm scope and sequence in the [implementation plan](../01-strategy/02-implementation-plan.md).
2. Configure and operate from the [admin runbook](../01-strategy/03-admin-runbook.md).
3. Tailor the [hybrid execution framework](../02-discovery/04-execution-framework/README.md).
4. Complete the [prebuild gates](../02-discovery/05-prebuild-gates.md).
5. Validate the experience against the [wireframes](../03-design/02-wireframes/README.md).

## Executor-owned outputs

A real implementation workspace should contain, as applicable:

- Salesforce metadata or a deployment manifest;
- field, picklist, validation, matching, duplicate-rule, report, dashboard, and list-view configuration;
- the nine core automation outcomes and their fault paths;
- import mappings, reconciliations, and protected source backups;
- UAT and regression results;
- deployment and rollback evidence;
- implementation-specific risks, decisions, gate evidence, and named owners.

Keep these outputs in the executor's secured workspace and source-control process. Do not commit personal data, credentials, production exports, or completed privacy-request evidence to this public framework.
